# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project
adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Landing page with the product's pricing, a live quota specimen, and
  `SoftwareApplication` structured data.
- Dashboard overview: request volume chart with keyboard navigation, quota
  meters, and a sortable, filterable endpoint table with sparklines.
- API keys screen: reveal, copy, revoke with confirmation, and create.
- Deterministic data layer with a fixed seed, so builds and tests agree.
- Static export configured for GitHub Pages, with the base path derived from
  the repository at deploy time.
- `sitemap.xml` and `robots.txt` generated at build time; the dashboard is
  excluded from the index.
- Open Graph card generated from the same design tokens as the site.
- Playwright suite covering layout, console health, document structure,
  base-path correctness, SEO output, axe-core under WCAG 2.1 AA in both
  themes, and the behaviour of every control.
- Screenshots and a demo GIF for the README, regenerated by `pnpm capture`.
- Deploy workflow publishing the export to GitHub Pages.

### Fixed

- Endpoint totals were multiplied by the number of days in the period, so the
  table summed to roughly thirty times the headline figure.
- The base path defaulted to empty in `next.config.ts` while links assumed
  `/meter`, which broke every internal link in the export.
- A visually-hidden table header anchored to the page instead of its scroll
  container, giving every table page a horizontal scrollbar.
- `--ink-3` sat at 3.2:1 against the page, below the 4.5:1 minimum.

## [0.1.0]

### Added

- pnpm workspace with a Turborepo task pipeline.
- `apps/web`: Next.js 16 app with the App Router and React 19.
- `apps/api`: Fastify 5 service with a `/health` endpoint.
- `packages/shared`: shared types, plans, and the health contract.
- Strict TypeScript, ESLint, and Prettier configuration.
- CI workflow running format, lint, typecheck, build, and an API smoke test.
- Issue templates, pull request template, and Dependabot configuration.
- MIT license, security policy, contribution guide, and code of conduct.
